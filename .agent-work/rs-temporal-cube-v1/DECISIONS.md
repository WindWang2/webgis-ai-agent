# DECISIONS — recommended implementation decisions (with evidence)

D1. **Put the cube runtime in a NEW module `app/lib/geo_analysis/rs_cube_runtime/` — do NOT edit `app/lib/modelops/**`.**
   Evidence: geo_analysis is the RS science home (`algorithms/remote_sensing.py` docstring L17-19: implementations live in `app/lib/geo_analysis/*`); `app/lib/modelops/` has 8 files touched by PR #1336 (PARALLEL_OWNERSHIP.md) — import `SAR_POLARIZATIONS`/`TemporalStackSpec` from `modelops.temporal` (L20/L24) but never edit there. Suggested layout: `app/lib/geo_analysis/rs_cube_runtime/{__init__.py, descriptor.py, alignment.py, gaps.py, preprocess.py, features.py, fusion.py, sampling.py, disclosure.py}` — flat siblings are also acceptable if the repo reviewer prefers the existing flat convention (`geo_analysis` is currently flat; flat files named `rs_cube_descriptor.py`, `rs_alignment.py`, `rs_gaps.py`, … avoid a new package).

D2. **`TemporalRasterCubeDescriptor` = refs-only pydantic model, additive-style, following `data_fabric/contracts.py` D1 conventions.**
   Fields: `cube_id`, `source_version`, `assets: List[AssetRef]` (each: `ref` (opaque `ref:raster/<id>` / fabric ref / DataObject id), `time_iso`, `role ∈ {optical, sar, cloud_mask, quality_mask}` (reuse `RS_ROLES` from `rs_cube.py` L40), `band|polarization ∈ SAR_POLARIZATIONS`), `grid` (identity dict from `_geometry_identity` rs_cube.py L97), `crs`, `times_sec`, `nodata`, `label`, plus `Optional` quality fields. All payloads stay behind refs ("ref 存在 ⟺ payload 可取回", `materialization_service.py` L34-38). Include `CONTRACTS_VERSION`-style additive-version field and `model_config = ConfigDict(extra="allow")` like contracts.py L40.

D3. **Typed gap semantics as a small closed enum + per-slice/per-pixel gap mask, not free-text disclosures.**
   `GapCode = Literal["missing_acquisition","cloud","shadow","nodata","layover","off_grid","below_quality"]`; a `GapMask` (T,H,W uint8 code plane, 0=valid) + `GapReport` (ratios per code, bounded counts). Bridge from existing signals: cloud (`rs_v3.cloud_qc_basic` L1701 / cloud_mask role), layover/shadow (`sar_v3.layover_shadow_mask` L577), nodata (`build_cube` L154-162), missing acquisitions (`slice_spacing_report` L76), quality (`quality>0` valid_mask L56). Keep `cube.disclosures` strings as *rendering* of the typed report, preserving honesty style ("诚实缺口…绝不静默插值", temporal_cube.py docstring L7-8).

D4. **Alignment produces a plan, never a silent resample.**
   `alignment.py`: `align_acquisitions(optical: […], sar: […], *, tol_days, grid_policy)` → `AlignmentPlan` (per target time: chosen optical asset ref + chosen sar asset ref + pairing method) or typed `MisalignmentError` listing offending grids (mirror `require_aligned` / `grid_coords_equal`, `cube_schema.py` L386/L442, and the "绝不静默重采样" red line, rs_cube.py docstring L14-16). Time pairing by nearest-acquisition within tolerance, disclosed in GapCode `missing_acquisition` when unmatched. Resampling, if ever added, must be an explicit declared plan step — default off.

D5. **Preprocessing as a declared, replayable `PreprocessingPlan` in our own module; steps map to existing functions.**
   Steps: `sar_despeckle(backend=lee|refined_lee|frost|kuan|gamma_map)` → `sar_filter.speckle_filter` (L444); `sar_calibrate(sigma0|gamma0)` → `sar_calibration.calibrate_sar` (L91) with `calibration_evidence_facts` (L236) attached; `thermal_noise_removal` (L287); `optical_cloud_qc` → `cloud_qc_basic`; `gap_policy=(keep_nan|exclude_pixel)` (never interpolate by default; phenology's bounded gap-fill stays opt-in and counted, per phenology.py L36 and temporal_cube.py L8). Plan is a frozen dataclass with a fingerprint (pattern precedent: `RasterChunkDescriptor` fingerprints, `chunk.py` L78; `AcquisitionPlan` replayability, contracts.py L163).

D6. **Feature extraction = orchestration over existing math; only new code for grouping + per-year composites.**
   Yearly/seasonal composites reuse `TemporalCube.climatology` (L92) and `sar_temporal.temporal_composite/medoid_composite` (L265/L344); percentiles reuse `temporal_stack_statistics` (L148); slope/amplitude reuse `rs_v3.temporal_features` (L1482); changepoint = existing CUSUM (`temporal.changepoint`, `algorithms/temporal.py` L112; tool in `app/tools/temporal_tools.py`); phenology proxies = `phenology.phenology_features` (L114). New code limited to water-year/season grouping and a bounded `TemporalFeaturePack` summary (stats-table-shaped output, refs for full rasters — the `science_temporal_tools` bounded-output contract, module docstring L14-17).

D7. **Fusion stack = one builder + two recipes, all evidence-level.**
   `fusion.build_joint_feature_stack(cube_desc, samples=None)` stacks per-pixel features from SAR (`vv`, `vh`, `vh_ratio` L434, coherence optional) × optical (`ndvi`, `evi` via `compute_spectral_index` L290, tasseled cap brightness/greenness/wetness L95) with per-feature validity from the GapMask. "Feature-level" = the stacked table; "late fusion" = existing evidence pattern: per-feature evidence blocks merged via `scientific_evidence.build_evidence` + `evidence_claim` graph is #1335-territory → do NOT write there; emit our own bounded evidence dict consumed by existing harness evidence channels. No ML training (repo honesty precedent: `modelops/temporal.py` L4 "不训练模型——只定义契约与纯校验").

D8. **Sampling: `attach_polygon_samples()` + spatial-block split by reusing `cv.spatial_block_folds`.**
   Polygons → `random_points_in_polygons`/`stratified_points_in_polygons` (`spatial_sampling.py` L175/L338) → features sampled from the joint stack via `geo_raster/windowed` reads → folds via `cv.spatial_block_folds(xy, folds)` (L49; optional `temporal_forward_folds` L76 for temporal split). Emit a samples **ref** + fold table with a leakage disclosure ("同一 block 永远同 fold" semantics per `modelops/evaluation.py` L274). Do not touch `modelops/evaluation.py` (#1336 adjacency).

D9. **Disclosure record `RSCoverageDisclosure` aggregated in `disclosure.py`; attached to run evidence and MapProduct tables.**
   Fields: gap ratios per GapCode, cloud %, shadow %, layover %, registration/alignment residual summary, per-source `source_version`, `calibration_evidence` (from `calibration_evidence_facts`), ENL/speckle backend notes. Bounded (`to_bounded_dict` style like `SkillPolicyDecision.to_bounded_dict`, policy.py L91). This becomes the single "coverage card" placed in `NodeEvidence` (plan.py L288) / run evidence snapshots (run_evidence.py L79).

D10. **Tool surface: extend existing register functions — freeze `app/tools/__init__.py`.**
    Add tools inside `app/tools/remote_sensing.py::register_rs_tools` (L111) or a new module re-exported from it (never edit `__init__.py` — #1336 conflict, PARALLEL_OWNERSHIP.md seam 1). Tool contract mirrors `science_temporal_tools.py`: inline arrays capped (`_TOOL_ARRAY_MAX_VALUES=4e6` precedent, remote_sensing.py L21), ref-channel for full rasters, `_attach_science_evidence` evidence block (L52). New tools (names kept kebab/snake per existing): `rs_cube_describe` (descriptor from refs), `rs_cube_align` (alignment plan), `rs_cube_preprocess`, `rs_temporal_features`, `rs_joint_stack`, `rs_sample_split`.

D11. **Capabilities + algorithms: additive domain-pack entries, new artifact type for the cube descriptor.**
    New `CapabilityDescriptor`s in `app/lib/gis/capabilities/raster.py` (or a new `remote_sensing_ext.py` pack wired into `capabilities/__init__.py::iter_capability_packs` L21 — 1-line edit in a #1336-untouched file): ids `rs_cube_describe`, `rs_temporal_features`, `rs_joint_fusion`, `rs_sample_split` (category="raster", domain="raster"). New `AlgorithmDescriptor`s in `algorithms/remote_sensing.py`/`algorithms/temporal.py` with `conformance_tests` pointing at new test node-ids (precedent L60-64) and honest `assumptions/limitations` (band semantics obligation pattern `RS_BAND_SEMANTICS_REQUIRED`, recipe_packs/remote_sensing.py L21-27). New artifact type `rs_cube_descriptor` in `artifacts.py::SEED_ARTIFACT_TYPES` (additive; `raster_surface` L118 / `remote_sensing_index` L129 precedent). Do NOT edit `capability_graph.py` (#1336) — projection picks registry changes up automatically (capability_registry.py docstring L5-8).

D12. **Kill-switch/feature-flag: env-var gate `RS_TEMPORAL_CUBE=1` default-on for pure additive paths, following `GIS_SKILL_POLICY` style.**
    Precedent: `SKILL_POLICY_ENV = "GIS_SKILL_POLICY"` + `policy_enabled()` (policy.py L59/L158); `ADS_DRIFT_BLOCKING` (CHANGELOG DS5); `REQUIRE_BROWSER`/`REAL_SERVICES` lane flags (pytest.ini comments). Tools registered unconditionally (they are inert until called); any planner/recipe behavior change gated by the env var so disabling restores master behavior byte-for-byte.

D13. **GIS Skill: one new core YAML `rs_temporal_cube.yaml` in `app/services/gis_harness/skills/library/core/`, data-driven only.**
    Follow `temporal.yaml` structure: `intent_patterns`, `capability_requirements` (criticality/hard_gate; hard-gates only for alignment + gap disclosure), `procedure.steps` with `evidence_requirements` (e.g. `coverage_disclosure`, `alignment_plan`, `split_report`), `output_artifacts: [rs_cube_descriptor, raster_surface, stats_table, chart_spec]`. Skill references capability ids validated against CapabilityRegistry (UBIQUITOUS_LANGUAGE.md "Relationships" L88). No policy.py code changes (#1335 boundary respected; SkillPolicy picks the skill up via resolver + YAML).

D14. **Recipe + MapProduct: new `recipe_packs/rs_temporal.py` reusing `_kit` helpers; charts/tables as artifact refs.**
    `CartographyRecipe` with `primary_cartography="raster_surface"`, `default_components=MAP_COMPONENTS_CHART` (temporal.py pack L10 precedent), obligations: gap/coverage disclosure + band/polarization semantics; `export_profile={"formats":["png","csv"], "chart": True}`. MapProductVersion needs **no schema change** — `compute_plan` + `artifact_ids` + `diff_summary` already carry steps/refs (project.py L475-487); temporal product = recipe_id + chart/table artifacts in the version's artifact set.

D15. **Tests: pure-numpy synthetic rasters; zarr-path tests only under the probe-gated honest-skip.**
    Follow `test_temporal_cube_v5.py` style (inline arrays, epoch-seconds, class grouping, Chinese docstrings). Cube/alignment/gap/fusion tests use small synthetic grids (e.g. (6,4,4), 2 years × monthly with holes); zarr/lakehouse round-trip tests go in `tests/data/` beside `test_lakehouse_rs_cube_v7.py` and self-skip when `zarr_available()` is False (`zarr.py` L98 honest-degrade). Register every new algorithm's tests in `conformance_tests`.

**Anti-decisions (explicit non-goals):** no resampling-by-default (D4), no ML model training (D7), no edits to `app/lib/modelops/**`, `capability_graph.py`, `app/tools/__init__.py`, `tests/conftest.py`, `app/main.py`, hotpath/evidence_claim/mission_runtime (boundaries), no new pytest markers (reuse none/light deps).
