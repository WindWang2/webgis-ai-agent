## 实施中发现并修复的关键问题

1. **对称内连接方向不可分**（W4）：纯传输成本下 (A,B) 与 (B,A) 等价 → 引入
   build 侧成本（右侧物化每行权重）后方向可分；同时子集拆分去重 bug
   （`sub < rest` 把两个方向的划分视为同一）导致漏掉合法计划 —— 双向枚举修复。
2. **边方位翻转改变用户可见形状**（W10）：attribute 边的方位归一（swapped）
   会翻转 `__right__` 归属 —— 移除翻转，边方位即输出形状契约。
3. **全无提示时的重排**（W6）：无 estimated_rows 提示时 DP 的 hash tie-break
   会任意改序 → 保持 given 序（V5 默认行为位级一致）。
4. **build 侧窗口放宽改变结果**（W11）：差分语料实锤 V5 窗口欠取漏配而 V6
   放宽后找回 —— 「优化器不改变结果语义」红线胜过覆盖改进，回到恒等窗口，
   放宽列为显式契约 follow-up。
5. **自适应循环缺 F1 跳后键提升**（W8）：补齐 `_chain_lift_next_join_key`
   调用点，链形自适应路径与 V5 行形状逐位一致。
6. **V5 工具契约测试锁定旧默认**（W10）：星形图测试改为 `engine="v5"` 显式
   锁定 V5 契约 + 新增 V6 树形执行对照测试。
