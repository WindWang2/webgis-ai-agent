# Combined backend regression repairs

The first backend run containing the issue repairs and all five reviewed PRs completed with 28,306 passing tests, 21 failures, 138 skips and six expected failures. Coverage was 85%. This report records the repairs to those failures; that run is not a passing release gate.

## Repairs and regression evidence

- **Integration inventory and selection:** preflight now inventories tracked and nonignored source files through Git instead of recursively reading runtime directories. The non-Git fallback rejects an exceeded file budget, tolerates concurrent deletion and does not traverse directory symlinks. Impact selection preserves coarse mapped suites under its target budget and includes changed test files themselves. Focused tests first reproduced all three selection/inventory defects. Preflight runtime fell from about 15 seconds to 0.5 seconds on this checkout.
- **Terrain conditional responses:** terrain URL signatures use minute issuance windows with nine to ten minutes of remaining validity. The TileJSON representation remains stable within a window; crossing the window produces a new ETag. Regression tests cover a conditional response one second later, window rollover and expiry. Authentication and scoped reference checks still precede the conditional response. An independent read-only review exercised the signing and inventory boundaries.
- **Scientific resolver lifecycle:** the cached algorithm resolver now detects replacement of its capability or algorithm registry. This prevents a temporary SDK test registry from contaminating subsequent scientific scenario selection. Three lifecycle regressions and an SDK-before-science ordering run cover the stale-cache failure. Raster tests explicitly retain the newly required valid-pixel coverage metadata, including null coverage for invalid inputs. Related suites passed 275 tests.
- **Metadata and Pi memory probes:** interaction-scope tools have their inspection category, and the actual analysis product gate is represented in the flag registry and test environment baseline. Pi leak fixtures now implement the real registry interface, use valid arguments and count weak references to objects created by the measured workload. The unchanged retention and memory limits also pass with debug logging enabled; the production Pi implementation was unchanged. Metadata checks passed 16 tests and the debug leak file passed four tests.
- **Mutation parity fixtures:** trace tests now use the mutation authority's actual deduplication state. Three parity cases were regenerated through the owning generator with an explicit case allowlist. Only their 12 hash fields changed: removing the newly included empty scene projection reproduces the previous hashes exactly. State, revision, review and counter fields remain unchanged. The related suite passed 109 tests with one existing generator-entry skip; the scene fingerprint regression also passed.
- **Documentation references:** ADRs 0284 and 0285 now name the implemented product-gate and analysis-tool modules. Terrain API documentation describes the short-lived signature returned in tile URLs accurately.

## Validation boundary

The root-focused suite passed 72 tests; its two remaining failures at that point required refreshing generated preflight and release-readiness inputs. The final owning-generator refresh, full backend rerun and isolated performance/cartography lanes are separate publication gates. Their final results belong in the aggregate PR validation record. These local checks do not establish live PostgreSQL/Redis, a production container rollout, paid model behavior or GPU rendering acceptance.

## Final gate follow-up

The first isolated backend performance lane passed 117 tests and failed three fixture assertions, with four skips. The topology workload now separately verifies the unchanged 5,000-detection budget, 200 returned examples and exact omitted count. The catalog workload declares EPSG:4326 and uses valid, binary-exact coordinates while retaining the 2,500-entry input, 2,000-entry scan bound and three bbox matches. The DAG workload executes under an explicit session and reads with its matching owner scope; missing and foreign scopes remain denied. Sizes, timing thresholds, baseline files and determinism checks were retained. The two data fixtures passed their focused rerun.

Release-readiness reports also embedded the absolute Python interpreter path in displayed commands. Two regression cases first failed under synthetic differing interpreter locations. Normalizing only that display makes snapshots portable while preserving the exact subprocess executable, gate status and detail. The related policy/supervisor suite passed 19 tests with one live-gate case reserved for refreshed artifacts. The artifact ledger is refreshed after readiness generation so preflight does not retain a transient stale-output result.

Bandit's container-listener finding is narrowly annotated on the Uvicorn command: the combined container must listen outside loopback for its published port, while deployment configuration controls exposure. The listener and runtime behavior are unchanged. No scanner rule or global exclusion was added. Deployment documentation now states the existing default refusal of unversioned business schemas, the explicit verified-adoption condition and the 0102 maintenance procedure consistently.

The next complete backend run passed 28,332 tests at 85.06% coverage, with one failure and three fixture setup errors. The failure was an older terrain test still requiring exactly 600 seconds of remaining validity; it now verifies the declared 540–600-second bound, scope binding and actual expiry without replacing Python's process-wide clock. The three errors came from a template-retry fixture using a shared application SQLite engine. It now uses a function-scoped database with the real uniqueness constraint, retry injection, payload recovery and 409 assertions intact. Terrain regressions passed 33 tests; template versioning regressions passed 12 tests. Production code and all thresholds were unchanged in this follow-up. Pi memory tests passed in that complete run; its shutdown warnings were not evidence of a Pi leak. The complete backend lane is rerun after these fixture repairs; its final result is recorded in the PR.

A subsequent run passed 28,334 tests at 85.06% coverage with two different failures. A 100,000-coordinate line test mixed deterministic bounds with a 300ms wall-clock assertion under coverage. The unchanged workload ran independently in about 28ms; its production algorithm body was unchanged. The backend keeps the projection/anchor bounds, while a separate test retains the original 300ms limit in the mandatory, coverage-free cartography lane. Collection checks verify both selections; the SVG regression group passed 40 tests.

The other failure was reproduced by leaving a deletion tombstone in a shared `sess-1` store: the scenario supplied clean state to one path while another correctly read the older store alias and refused restoration. Its fixture now supplies fresh real memory-session and MapSpec stores consistently. The same injected alias pollution failed before the fixture repair and passed afterward. Existing deletion rejection cases followed by the full GIS-context suite passed 177 tests. Production deletion protection, current-basis authority, thresholds and golden files were unchanged. The final complete backend and cartography lanes are run again after these isolated test repairs.

## Final validation outcome

The final full backend selection passed 28,334 tests and failed two artifact checks, with no errors and 85.05% coverage. Both failures came from the quality reference index: a newly staged test file became visible to tracked-file discovery after the earlier manifest generation. The owning refresh was repeated on the final tracked file set. Its manifest delta added that test reference and updated the derived fingerprint; it removed no references or policy fields.

After that refresh, all 21 tests in the two affected files passed with `--cov-append`, the original 75% coverage gate and 180-second timeout. The full-run coverage was retained at 85.05%. The complete quick quality lane also passed, as did the 80 API/schema/realtime/generated-artifact contracts. An independent comparison verified all 7,246 functional files (about 74.2 MB) were byte-identical to the pre-refresh source snapshot.

There is passing execution evidence for 28,336 unique backend cases across the complete selection and focused repair verification. The original complete run remains recorded as exit 1 with two failures; it is not relabeled as a single clean full invocation. The final PR distinguishes those results and records the other local lanes and acceptance limits.
