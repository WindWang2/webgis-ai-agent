## Additional confirmed fixes in this pass

- A slow old-turn unregister can overlap a successor starting after the inner release. The old outer backstop previously unconditionally cleared `_active_turn_sid`, weakening successor abort routing. It now clears only its own current-turn identity; a real two-prompt slow-unregister test preserves the successor's sid/current turn.
- AC07 `test_plan_repairs_required_overflow_kept_action` exposed a real composer bug: exclusive zones forcibly reopened to capacity1 even when explicitly disabled with0. Exclusive is now an upper bound, so explicit0 stays closed in initial placement, rehoming and overflow. Required components retain shrink/keep_required when all slots are disabled. An additional test confirms both zero closure and the exclusive ceiling against an attempted99 capacity. No expected behavior was weakened.
- The old stream/nonstream parity spy did not create a durable running turn, so the new authoritative settlement claim correctly refused it. The fixture now calls the real runtime begin/end and supplies its actual store, retaining the original host assertions. Canonical lazy-module seams are patched in the new tests to prevent import-order pollution.
